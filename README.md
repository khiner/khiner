I build tools for audio, graphics, and physical simulation.

[karlhiner.com](https://karlhiner.com)

### Physical Audio & Simulation

- [MeshEditor](https://github.com/khiner/MeshEditor): Mesh editor that turns 3D geometry into playable physical audio models
- [AcousticSolver](https://github.com/khiner/AcousticSolver): Acoustic solvers and differentiable physical models for Apple Silicon
- [SurfaceAudio](https://github.com/khiner/SurfaceAudio): Sound synthesis for friction, rubbing, scraping, scratching, and rolling
- [FastFEM](https://github.com/khiner/FastFEM): Finite-element library for tetrahedralization and modal analysis on Apple Silicon
- [RigidBodyPhysics](https://github.com/khiner/RigidBodyPhysics): Rigid body physics and collision detection on Apple Silicon
- [mesh2audio](https://github.com/khiner/mesh2audio): Convert meshes into physical audio models and play them by striking vertices (replaced by [MeshEditor](https://github.com/khiner/MeshEditor))

### Audio Tools & DSP

- [flowgrid](https://github.com/khiner/flowgrid): Persistent ImGui editor for Faust audio programs
- [faustlens](https://github.com/khiner/faustlens): Bidirectional editor and compiler for Faust
- [tree-sitter-faust](https://github.com/khiner/tree-sitter-faust): Faust grammar for Tree-sitter, available in nvim-treesitter
- [jaxdsp](https://github.com/khiner/jaxdsp): Differentiable audio processors built with JAX and controlled from the browser
- [MetalRealtimeAudio](https://github.com/khiner/MetalRealtimeAudio): Experiments with latency limits for realtime GPU-generated audio
- [AutoSampler](https://github.com/khiner/AutoSampler): Max for Live instrument that finds and plays samples matching incoming MIDI notes
- [midi_markov](https://github.com/khiner/midi_markov): Generate MIDI from an input file using a Markov chain
- [DrumClassification](https://github.com/khiner/DrumClassification): Drum classification model
- [BeatBot](https://github.com/khiner/BeatBot): Sample-based Android beat sketchpad with an Ableton-style timeline note editor, multitouch editing, and OpenGL UI
- [billboard-chordify-scraper](https://github.com/khiner/billboard-chordify-scraper): Chart and chord scraper with Roman numeral analysis for 6,400 songs

### Graphics & Visualization

- [GeoLDMViz](https://github.com/khiner/GeoLDMViz): 3D viewer for generated molecules and GeoLDM diffusion chains
- [ProcessingRayTracer](https://github.com/khiner/ProcessingRayTracer): Ray tracing, implicit surfaces, and mesh manipulation in Processing
- [ImGuiVulkanHppImage](https://github.com/khiner/ImGuiVulkanHppImage): Vulkan-Hpp rendering inside an ImGui window
